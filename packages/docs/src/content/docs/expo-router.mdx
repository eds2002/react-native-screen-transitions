<Note>
  The Expo Router integration uses Expo Router's Standard Navigator integration and requires Expo Router 56.2.10 or later. On Expo Router 58 (Expo SDK 58) and later it uses the stable `integrateWithRouter` API; earlier versions use `unstable_integrateWithRouter`.
</Note>

## Add Blank Stack to a layout

Import `BlankStack` from the Expo Router entry point:

```tsx
// app/_layout.tsx
import Transition from "react-native-screen-transitions";
import { BlankStack } from "react-native-screen-transitions/expo-router";

export default function RootLayout() {
  return (
    <BlankStack>
      <BlankStack.Screen name="index" />
      <BlankStack.Screen
        name="detail"
        options={Transition.Presets.SlideFromBottom()}
      />
    </BlankStack>
  );
}
```
