`useScreenAnimation()` returns a Reanimated derived value with the same interpolation props passed to `screenStyleInterpolator`. The no-argument call and `{ depth: 0 }` require a local screen context and throw when used outside it.

```tsx
import { useScreenAnimation } from "react-native-screen-transitions";

const animation = useScreenAnimation();

const style = useAnimatedStyle(() => {
	const { current } = animation.value;

	return {
		opacity: current.progress,
		transform: [{ translateY: current.gesture.y }],
	};
});
```

Target another transition scope with `depth`:

```tsx
const currentAnimation = useScreenAnimation({ depth: 0 });
const parentAnimation = useScreenAnimation({ depth: -1 });
const childAnimation = useScreenAnimation({ depth: 1 });
```

`depth: 0` resolves the current transition. Negative values resolve ancestors. Positive values resolve descendants.

Non-current targets can return `null`, so check `animation.value` before reading it.

## Named targets

Set `transitionKey` in a screen's options, then pass that key to the hook:

```tsx
// Screen options
{ transitionKey: "feed" }

// Inside a React component
const feedAnimation = useScreenAnimation("feed");
```

The key must be unique among mounted screens. The derived value is `null` while the target is unavailable. Call this hook from a component, not from `screenStyleInterpolator` or another worklet.


Named lookup can also be used outside a screen context. The target must be registered in Blank Stack's screen topology; passing a name does not create a screen or keep its effects running. Relative depth lookup needs a local screen from which to resolve the relationship.

## Stack progress and inactive screens

`animation.get().stackProgress` includes the current screen and the routes above it in its navigator. To keep an animation reader updating while its own screen is covered, use `inactiveBehavior: "keep"` on that screen. `hide` and `pause` preserve state but pause effects. See [Stack progress](/custom-animations#stack-progress) and [Inactive Behavior](/inactive-behavior).
