`useScreenAnimation()` returns a Reanimated derived value with the same interpolation props passed to `screenStyleInterpolator`.

```tsx
import { useScreenAnimation } from "react-native-screen-transitions";

const animation = useScreenAnimation();

const style = useAnimatedStyle(() => {
	const { current } = animation.value;

	return {
		opacity: current.progress,
		transform: [{ translateY: current.gesture.y }],
	};
});
```

Target another transition scope with `depth`:

```tsx
const currentAnimation = useScreenAnimation({ depth: 0 });
const parentAnimation = useScreenAnimation({ depth: -1 });
const childAnimation = useScreenAnimation({ depth: 1 });
```

`depth: 0` resolves the current transition. Negative values resolve ancestors. Positive values resolve descendants.

Non-current targets can return `null`, so check `animation.value` before reading it.

## Named targets

Set `transitionKey` in a screen's options, then pass that key to the hook:

```tsx
// Screen options
{ transitionKey: "feed" }

// Inside a component under a transition scope
const feedAnimation = useScreenAnimation("feed");
```

The key must be unique among mounted screens. The derived value is `null` while the target is unavailable. Call this hook from a component, not from `screenStyleInterpolator` or another worklet.
