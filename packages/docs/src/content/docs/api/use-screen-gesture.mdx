`useScreenGesture()` returns the screen navigation pan gesture ref. Use it when a custom Gesture Handler gesture needs a relationship with the navigator gesture.

```tsx
import { Gesture } from "react-native-gesture-handler";
import { useScreenGesture } from "react-native-screen-transitions";

const screenGesture = useScreenGesture();

const pan = Gesture.Pan();
if (screenGesture) {
  pan.requireExternalGestureToFail(screenGesture);
}
```

Target an ancestor navigator with negative depth:

```tsx
const parentGesture = useScreenGesture({ depth: -1 });
```

`depth: 0` reads the current screen, negative depth resolves ancestors, and positive depth resolves descendants through Blank Stack's screen topology. The hook returns `null` when the target is unavailable, including when there is no local screen context. Check for a gesture before passing it to Gesture Handler.
