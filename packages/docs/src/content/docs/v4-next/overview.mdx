v4 is the next major line of `react-native-screen-transitions`. It requires the React Native New Architecture and replaces layout-driven navigation masks with first-class clip presentations rendered by `react-native-smooth-clip-view`.

## What changed

- Transition slots may emit a whole-object `clip` beside `style` and `props`.
- `Transition.ClipView` and `Transition.Boundary.ClipView` provide fixed-footprint apertures with correct hit testing and accessibility.
- Built-in zoom and reveal transitions project clip geometry directly. Interactive frames are batched once per screen; eligible settlement can move to one native group without per-frame JSI writes.
- Navigation masks preserve both existing mask IDs and `navigationMaskEnabled`, but no longer require `@react-native-masked-view/masked-view`.
- Deprecated `Transition.MaskedView` is now a geometric compatibility adapter. Alpha-mask semantics are intentionally not emulated.

Native promotion remains internally gated. Scalar streaming is the correctness baseline, and promotion stays disabled by default until the physical-device continuity and frame-time gates pass.

## Compatibility floor

v4 requires Fabric, React Native 0.86+, React 19.2+, Reanimated 4.5+, Worklets 0.10+, SmoothClip 0.3, iOS 16.4+, and Android API 33+.
